# Marcy Lab School JavaScript Challenges

This repository contains JavaScript exercises completed as part of a Marcy Lab School prep programming session. The challenges focus on developing core programming skills in a beginner-friendly format.

## Contents

- **Greeting Function:** Returns a personalized morning greeting.
- **Dog Years Converter:** Converts human years into dog years.
- **Temperature Checker:** Determines if a temperature is below freezing.
- **FizzBuzz:** Classic loop and condition exercise.
- **Celsius to Fahrenheit Converter:** Converts Celsius values to Fahrenheit.
- **Goldfish Years Function:** Experimental age conversion logic based on a creative prompt.

## File

- `index.js` – All challenge functions and logs are stored here.
